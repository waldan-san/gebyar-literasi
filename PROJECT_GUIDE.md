# PROJECT GUIDE

## Digital Guestbook – SMAN 1 Boyolangu

### 1. Identitas Proyek

- **Nama proyek:** Digital Guestbook
- **Sekolah:** SMAN 1 Boyolangu
- **Kegiatan:** Gebyar Literasi – Gelar Karya
- **Tema pameran:** Kecamatan Gondang, Kabupaten Tulungagung, Jawa Timur
- **Jenis proyek:** Website buku tamu digital
- **Target pengguna:** Pengunjung pameran
- **Perangkat utama:** Satu laptop yang disediakan di lokasi acara
- **Durasi penggunaan:** Satu hari
- **Deadline:** Website harus siap dan sudah diuji paling lambat H-1 acara.

### 2. Tujuan Proyek

Membuat website buku tamu digital yang memungkinkan pengunjung mengisi data kehadiran dan membubuhkan tanda tangan digital menggunakan mouse atau touchpad.

Website harus:

- Mudah digunakan oleh pengunjung dari berbagai kalangan.
- Memiliki tampilan profesional, sederhana, dan menarik.
- Dapat digunakan berkali-kali oleh pengunjung berbeda.
- Menyimpan data secara konsisten.
- Memiliki fitur pengelolaan dan pencadangan data.
- Tidak membutuhkan proses instalasi yang rumit.
- Dapat dipindahkan dan dijalankan pada laptop lain.

### 3. Konsep Utama

Website menggunakan konsep **Vintage Editorial – Historical Atlas**.

Karakter desain:

- Nuansa kertas buku sejarah.
- Warna krem, hijau tua, dan cokelat.
- Minimalis dan elegan.
- Memiliki identitas kegiatan pendidikan.
- Tidak terlalu formal, tetapi tetap profesional.
- Ilustrasi digunakan secara terbatas.

### 4. Struktur Website

Website terdiri dari empat bagian utama:

1. Welcome Page
   - Identitas sekolah.
   - Judul Gebyar Literasi – Gelar Karya.
   - Tema Kecamatan Gondang.
   - Deskripsi singkat.
   - Tautan website materi pameran.
   - Tautan Google Maps.
   - Tombol Isi Buku Tamu.

2. Registration Page
   - Formulir identitas pengunjung.
   - Kolom nama.
   - Kolom jabatan/kelas.
   - Kolom NIS.
   - Area tanda tangan digital.
   - Tombol hapus tanda tangan.
   - Tombol simpan.

3. Success Page
   - Konfirmasi data berhasil disimpan.
   - Ucapan terima kasih.
   - Tombol kembali ke halaman awal.
   - Formulir harus siap digunakan pengunjung berikutnya.

4. Admin Dashboard
   - Jumlah pengunjung.
   - Daftar pengunjung.
   - Detail data.
   - Pencarian nama.
   - Ekspor CSV.
   - Backup dan restore JSON.
   - Cetak daftar pengunjung.
   - Penghapusan data dengan konfirmasi.

### 6. Ketentuan Penggunaan

- Website digunakan oleh satu pengunjung dalam satu waktu.
- Setelah data berhasil disimpan, pengunjung berikutnya dapat mengisi formulir baru.
- Data pengunjung harus tetap tersimpan setelah halaman dimuat ulang.
- Pengunjung tidak boleh melihat data pengunjung sebelumnya.
- Halaman admin harus dipisahkan dari halaman pengunjung.
- Harus tersedia fitur backup data.
- Data tidak boleh otomatis dikirim ke layanan eksternal.

### 7. Aturan Privasi

- Kumpulkan data hanya sesuai kebutuhan kegiatan.
- NIS sebaiknya hanya diwajibkan bagi pengunjung yang merupakan siswa apabila relevan.
- NIS harus disimpan sebagai teks, bukan angka, agar angka nol di depan tidak hilang.
- Tanda tangan digital termasuk data pribadi dan harus dijaga.
- Jangan mengirim data pengunjung ke server atau layanan eksternal tanpa persetujuan.
- Jangan menampilkan data pengunjung kepada pengunjung lain.

### 8. AI Working Rules

AI yang mengerjakan proyek wajib mengikuti aturan berikut:

1. Baca seluruh file dokumentasi proyek sebelum memulai pekerjaan.
2. Jadikan dokumentasi ini sebagai sumber acuan utama.
3. Jangan mengubah konsep desain tanpa alasan yang jelas.
4. Jangan menambahkan fitur yang tidak diperlukan untuk MVP.
5. Jangan membuat website sebelum pengguna meminta atau menyetujui tahap implementasi.
6. Jangan mengarang URL, informasi sekolah, maupun materi pameran.
7. Jelaskan perubahan penting sebelum melakukan perubahan besar.
8. Prioritaskan website yang berfungsi dan stabil dibandingkan efek visual.
9. Utamakan solusi gratis atau yang tidak membutuhkan biaya.
10. Pastikan website dapat dipindahkan ke laptop lain.
11. Jangan menganggap data lokal otomatis tersinkronisasi antarlaptop.
12. Jangan mengklaim sistem admin PIN sederhana sebagai keamanan tingkat tinggi.

### 9. Prioritas Keberhasilan

Urutan prioritas:

1. Formulir dapat digunakan.
2. Tanda tangan digital berfungsi.
3. Data tersimpan dengan benar.
4. Pengunjung dapat mengisi secara bergantian.
5. Admin dapat melihat dan mengelola data.
6. Backup dan restore berfungsi.
7. Tampilan sesuai konsep desain.
8. Website siap digunakan pada laptop acara.

### 10. Definisi MVP

MVP adalah versi website yang sudah memiliki:

- Welcome Page.
- Formulir pengunjung.
- Tanda tangan digital.
- Penyimpanan data.
- Halaman konfirmasi.
- Dashboard admin.
- Ekspor dan backup data.
- Tampilan responsif.

Fitur tambahan hanya boleh dikerjakan jika fitur utama sudah stabil dan waktu masih mencukupi.
