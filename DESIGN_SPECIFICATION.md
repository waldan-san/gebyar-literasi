# DESIGN SPECIFICATION

## Digital Guestbook – SMAN 1 Boyolangu

### 1. Design Direction

Konsep desain: **Vintage Editorial – Historical Atlas**

Website harus terasa seperti halaman buku sejarah atau atlas lama yang dimodernisasi menjadi website pendidikan.

Desain tidak boleh terlalu ramai, terlalu klasik, atau terlihat seperti website museum yang berat.

Karakter utama:

- Minimalis.
- Editorial.
- Elegan.
- Hangat.
- Informatif.
- Profesional tetapi tetap ramah.

### 2. Color Palette

Gunakan palet warna berikut sebagai pedoman utama.

| Nama            | Hex     | Penggunaan          |
| --------------- | ------- | ------------------- |
| Parchment Cream | #F3EBDD | Background utama    |
| Forest Green    | #344638 | Warna utama         |
| Antique Brown   | #A58B65 | Aksen               |
| Vintage Beige   | #D8C9AA | Background sekunder |
| Olive Green     | #727D60 | Aksen tambahan      |
| Dark Ink        | #4B4438 | Teks utama          |

Ketentuan:

- Gunakan warna krem sebagai dasar tampilan.
- Hijau tua digunakan untuk tombol utama dan elemen penting.
- Cokelat digunakan sebagai aksen.
- Pastikan kontras teks tetap nyaman dibaca.
- Hindari penggunaan terlalu banyak warna.

### 3. Typography

Gunakan maksimal dua keluarga font utama.

Rekomendasi:

- Heading: serif yang elegan.
- Body text: sans-serif yang sederhana dan mudah dibaca.

Contoh:

- Playfair Display untuk heading.
- Inter atau Lato untuk body.

Jangan menggunakan terlalu banyak variasi font.

### 4. Layout

#### A. Welcome Page

Elemen:

1. Nama sekolah.
2. Judul kegiatan.
3. Tema pameran.
4. Deskripsi singkat.
5. Tautan website materi.
6. Tautan Google Maps.
7. Tombol Isi Buku Tamu.

Desain:

- Layout terpusat dan bersih.
- Judul menjadi fokus utama.
- Ilustrasi peta atau ornamen sejarah digunakan secara terbatas.
- Tombol utama terlihat jelas.
- Tidak menggunakan animasi berlebihan.

#### B. Registration Page

Elemen:

1. Judul formulir.
2. Nama lengkap.
3. Jabatan/Kelas.
4. NIS.
5. Area tanda tangan.
6. Tombol hapus tanda tangan.
7. Tombol simpan.

Desain:

- Formulir berada dalam satu panel yang rapi.
- Label setiap kolom jelas.
- Area tanda tangan cukup luas.
- Tombol hapus dan simpan mudah dibedakan.
- Berikan pesan kesalahan yang mudah dipahami.

#### C. Success Page

Elemen:

- Ikon atau ilustrasi keberhasilan sederhana.
- Pesan bahwa data berhasil disimpan.
- Ucapan terima kasih.
- Tombol kembali ke halaman awal.

Desain:

- Sederhana.
- Tidak berlebihan.
- Memberikan kepastian bahwa proses berhasil.

#### D. Admin Dashboard

Elemen:

- Judul dashboard.
- Statistik jumlah pengunjung.
- Tabel data pengunjung.
- Pencarian.
- Tombol ekspor.
- Tombol backup.
- Tombol restore.
- Tombol cetak.
- Tombol hapus data.

Desain:

- Mengutamakan keterbacaan.
- Tabel mudah dipahami.
- Tombol tindakan dikelompokkan secara logis.
- Tindakan berisiko harus memiliki konfirmasi.

### 5. Responsive Design

Website harus dapat digunakan pada:

- Laptop.
- Desktop.
- Tablet.

Prioritas utama adalah tampilan laptop karena perangkat tersebut akan digunakan saat acara.

Pada ukuran layar lebih kecil:

- Formulir harus tetap mudah digunakan.
- Tombol tidak boleh saling bertumpuk.
- Tabel admin harus dapat diakses dengan nyaman.

### 6. Signature Area

Area tanda tangan harus:

- Menggunakan latar belakang terang.
- Memiliki batas area yang jelas.
- Mendukung mouse dan touchpad.
- Mendukung layar sentuh jika tersedia.
- Memiliki tombol hapus tanda tangan.
- Memiliki petunjuk singkat.

Contoh petunjuk:
"Silakan bubuhkan tanda tangan pada area yang tersedia."

### 7. Design Restrictions

Hindari:

- Gradien warna mencolok.
- Efek 3D.
- Animasi berlebihan.
- Ilustrasi besar yang tidak diperlukan.
- Ornamen yang terlalu ramai.
- Font dekoratif yang sulit dibaca.
- Terlalu banyak card.
- Tampilan seperti template dashboard generik.

### 8. Design Priority

Prioritas desain:

1. Mudah digunakan.
2. Informasi jelas.
3. Konsisten.
4. Sesuai tema.
5. Responsif.
6. Estetis.

Jangan mengorbankan kemudahan penggunaan demi tampilan visual.
